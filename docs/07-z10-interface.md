# Eversolo DAC-Z10 的 RCA 搭配

使用者已確認使用 Eversolo DAC-Z10，並選 RCA 維持簡單架構。DAC-Z10 本身具前級及音量控制，本專案按下列接法設計：

```mermaid
flowchart LR
    SRC[數位訊源] --> Z[DAC-Z10\nDAC＋前級／音量控制]
    Z -->|左右 RCA Pre-out| AMP[LM3886 純後級\n內建電源、固定增益]
    AMP --> SPK[左右喇叭]
```

## 電平與增益

原廠列出的 RCA 輸出為 **2.5Vrms／0dBFS**，DAC-Z10 具 R2R 音量控制與前級功能。[Eversolo 官方產品規格](https://www.eversolo.com/en/products/dac-z10)

本後級保留 20k／1k 回授，IC 中頻增益 21 倍，含輸入串阻後約 20.09 倍。這是電路固定增益，沒有在後級增加音量旋鈕。

| 項目 | 初步結果 |
|---|---:|
| 40W／8Ω 所需後級輸入 | 約 0.891Vrms |
| 50W／8Ω 所需後級輸入 | 約 0.996Vrms，僅延伸目標 |
| 2.5Vrms 降至 40W 所需輸入的電壓衰減 | 約 8.96dB |
| 後級中頻輸入阻抗 | 約 22.48kΩ；1M 與 23k 並聯的估算 |

衰減量由 `20log10(2.5/0.891)` 推算，假設數位訊號 0dBFS 及原廠標準輸出條件。這不是經校正的 Z10 面板音量位置；聲道增益、平衡調整、類比輸入與實際訊號電平可能不同。2.5Vrms 直接全電平送入會要求後級超出目前輸出目標，應使用 Z10 的可調前級輸出。

## 使用與驗證方式

1. 從 Z10 左右 **RCA 輸出** 接到後級 RCA 輸入，使用短的屏蔽訊號線。
2. 讓 Z10 保持音量控制有效，關閉音量直通（volume passthrough）；初次配對先從低音量開始。
3. 可按機上提供的功能設定低開機音量與最大音量限制。原廠韌體說明列有這些功能，實際選單以使用者機上版本為準；本次不變更設備韌體或設定。[官方下載與版本說明](https://www.eversolo.com/en/downloads/dac-z10)
4. 原型先在假負載上以已知測試訊號確認 Z10 的音量位置、輸出電壓與後級削波點，再設定實際音量上限。正常聆聽仍依需要降低音量。

目前未取得 RCA 輸出阻抗的原廠數值，先不把其數值填入電路計算；以實際測試確認接入約 22.48kΩ 負載後的增益與頻率響應。自動 trigger 聯動不屬於本版已完成電路，後級電源由本機開關控制，啟停及喇叭保護另待完成。
