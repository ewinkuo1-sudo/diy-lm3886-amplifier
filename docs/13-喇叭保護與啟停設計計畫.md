# 13 喇叭保護與啟停設計計畫（V0.4）

> **設計計畫，不是已完成設計，也沒有任何硬體量測。** 架構、時序、介面與計算的設計草案見 [14 V0.4 控制與保護板設計草案](14-V0.4-控制與保護板設計草案.md)（2026-09-22）；原理圖與 PCB 仍未開始。

## 為什麼要做

LM3886 輸出級失效時 pin 3 會被拉到接近 VCC 或 VEE（±30V 等級），該電壓直接加在喇叭音圈上。IC 內建的 SPiKe 保護的是 IC 自己，不保護喇叭。本機現有的 pin 8 靜音支路（R8/22k＋JP1＋C8/100µF）是**板級測試跳線**，IC 已失效時無法切斷輸出。這是本機與成品後級之間唯一有實質安全風險的缺口。

## 必須設計的功能

| # | 功能 | 必要性 | 要求 |
|---|---|---|---|
| P1 | ±DC 偵測 | 必要 | 正負兩方向都要偵測，單向不合格。門檻典型 ±1～2VDC |
| P2 | 開機延遲接通 | 必要 | 電源建立、DC 穩定後才接通喇叭，典型 2～5 秒 |
| P3 | 關機快速斷開 | 必要 | **從 12Vac 繞組整流前取樣**；市電斷開時 12Vac 立即消失，主電容的 ±30V 還能撐數百毫秒到數秒，這個時間差就是安全窗口。不可從整流後 DC 取樣 |
| P4 | 繼電器 DC 分斷能力 | 必要 | 見下節，最容易選錯 |
| P5 | 單軌掉電偵測 | 建議 | 一軌保險絲熔斷時，另一軌會把輸出推向該極性 |
| P6 | 過溫偵測 | 選配 | LM3886 有內建熱關斷，優先度低 |
| P7 | 一次側軟啟動 | 必要 | 每軌 20,000µF、合計 40,000µF，上電湧流可達數十安培，會打跳斷路器。標準做法是一次側串 NTC 或功率電阻，延遲 0.5～2 秒後以繼電器旁通 |

啟停時序：上電＝軟啟動旁通 → 電源穩定 → 解除 MUTE → 延遲 → 繼電器接通喇叭；掉電＝偵測 12Vac 消失 → 立即斷開繼電器；故障＝偵測 DC → 立即斷開繼電器。**兩個 MUTE 節點不得直接相接**（既有規則），控制電路要維持這個隔離。

## 繼電器選型：交流額定不等於直流額定

標示「10A 250VAC / 10A 30VDC」的繼電器，實際工況是切斷帶著 ±30V DC、流過低阻抗喇叭的電路。直流沒有過零點，拉弧不會自行熄滅，觸點可能燒黏而失去保護作用。

| 項目 | 要求 |
|---|---|
| DC 分斷電壓 | ≥ 軌壓（±30V 等級 → 至少 30VDC，建議 48VDC 以上） |
| DC 分斷電流 | 軌壓 ÷ 喇叭阻抗：±30V／8Ω ≈ 3.75A；4Ω ≈ 7.5A |
| 觸點材質 | AgSnO₂ 或 AgNi，避免純銀 |
| 接點形式 | 雙刀（DPDT），左右聲道各一組。部分設計把兩組觸點串聯給同一聲道以分擔拉弧電壓，成本翻倍但安全性顯著提升，值得評估 |
| 線圈電壓 | 配合 12Vac 整流後約 15～16Vdc → 選 DC12V 線圈，須確認 16V 下耐受，或加穩壓 |

## 目前的決策狀態

- **方案 A（現成 UPC1237 模組，$258）**：AC12–18V 直入、約 3 秒延遲、約 1VDC 起控。便宜成熟，但賣家公告部分二手以全新欄位上架，「300W×2」是文案不是規格，**板上繼電器的 DC 分斷能力通常沒標**。
- **方案 B（自製保護板）**：電路全透明、繼電器可自選，代價是多一輪 PCB 打樣與除錯。
- **目前傾向**：先買一片方案 A **作為驗證與學習用，不直接裝進成機**；到貨後反推電路圖、實測延遲與 DC 門檻、查繼電器料號的 DC 分斷規格。不合格（極可能）就換繼電器或轉方案 B。**成機用哪一版尚未決定。**
- ⚠️ **12Vac 繞組電流容量確認前，不得下單保護板。** 賣場標「200W」是整顆變壓器的宣稱值，不是該繞組的配額。

驗收方法（未來實機，全部在假負載上做，不接真實喇叭）：開機延遲看觸點接通時 DC 是否已在門檻內；正負 DC 故障各以電阻從 VCC／VEE 注入輸出節點；掉電時觸點須先斷、輸出後衰減；拆一軌保險絲模擬單軌掉電；播大動態低頻至接近削波確認不誤動作。DC 注入會讓 IC 承受異常工況，**等 IC 到貨且有備品再做**，或先以訊號產生器模擬偵測節點電壓。整合進 [04 上電與驗收](04-上電與驗收.md)。
