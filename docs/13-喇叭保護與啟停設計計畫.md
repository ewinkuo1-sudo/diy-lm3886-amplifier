# 13 - 喇叭保護與啟停設計計畫（V0.4 規劃）

> 2026-09-19 建立。本文件是**設計計畫與交接指示**，不是已完成設計，也沒有任何硬體量測。
> 現況：變壓器與 LM3886T 已下單待到貨，保護電路完全未設計。

## 1. 為什麼現在做這件事

`docs/01-設計規格.md` 已載明：「一次側保險絲與浪湧控制、單軌掉電監測、喇叭 DC 偵測及輸出繼電器尚未完成」，並明確指出「不能以靜音功能替代」。

這是本機與成品後級之間**唯一有實質安全風險的缺口**。LM3886 輸出級失效時，pin 3 會被拉到接近 VCC 或 VEE（±30V 等級），該電壓將直接加在喇叭音圈上。IC 內建的 SPiKe 保護保護的是 IC 自己，不保護喇叭。

本機現有的 pin 8 靜音支路（R8/22k + JP1 + C8/100µF）是**板級測試跳線**，它在 IC 已失效時無法切斷輸出。

## 2. 12Vac 輔助繞組

已下單變壓器含一組 12Vac 繞組（賣場標示，未經確認）。它是本計畫的供電來源。

**已知：**
- 12Vac 經全橋整流濾波約 15～16Vdc，空載可能更高。
- UPC1237 類保護板典型輸入為 **AC12–18V 直入**，板上自帶整流。若選 AC 輸入型，則不需另做 DC 穩壓。

**未知，到貨後必須實測（阻斷條件）：**

| 項目 | 方法 | 判定 |
|---|---|---|
| 12Vac 繞組是否真實存在、線色 | 目視 + 萬用電表 AC 檔 | 對照賣場標示 |
| 空載電壓 | AC110V 通電，量測 12Vac 兩端 | 記錄實際值，可能高於 12V |
| 繞組是否與 22Vac 獨立（不共地） | 電阻法逐對量測導通 | 必須完全獨立 |
| 可供電流 | **無法直接量測**，需查賣場/廠商或以已知負載測試壓降 | 繼電器線圈 + 控制電路預估需求見 §5 |

⚠️ **繞組電流容量未確認前，不得下單保護板。** 賣場標示「200W」是整顆變壓器的宣稱值，不是 12Vac 繞組的配額。

## 3. 保護功能需求清單

本機所需的保護動作，依重要性排序：

| # | 功能 | 必要性 | 說明 |
|---|---|---|---|
| P1 | **±DC 偵測** | 必要 | 正負兩方向的 DC 偏移都要偵測。單向偵測不合格 |
| P2 | **開機延遲接通** | 必要 | 電源建立、DC 穩定後才接通喇叭。典型 2～5 秒 |
| P3 | **關機快速斷開** | 必要 | 偵測到市電消失時，必須**早於**主電容放完電之前斷開 |
| P4 | **繼電器 DC 分斷能力** | 必要 | 見 §5，這是最容易選錯的一項 |
| P5 | 單軌掉電偵測 | 建議 | 一軌保險絲熔斷時，另一軌會把輸出推向該極性 |
| P6 | 過溫偵測 | 選配 | LM3886 有內建熱關斷，優先度低 |
| P7 | 一次側浪湧限制（軟啟動） | 必要 | 見 §6。20,000µF/軌 的充電湧流會打跳斷路器 |

**P1 的觸發門檻**：典型設定約 ±1～2VDC。過低會誤動作（音樂低頻可能被誤判），過高則喇叭已受損。UPC1237 典型約 1VDC 起控。

**P3 的實現方式**：從 12Vac 繞組（整流前）取樣。市電斷開時 12Vac 立即消失，而主電容上的 ±30V 還能維持數百毫秒到數秒——這個時間差正是安全斷開的窗口。**不可從整流後的 DC 取樣**，因為輔助電源自己的濾波電容會延遲這個訊號。

## 4. 方案選擇

### 方案 A：UPC1237 現成模組

- 露天已查到候選：$258，賣方稱獨立 AC12–18V、約 3 秒延遲、約 1VDC 起控
- **優點**：便宜、成熟、AC 輸入直接吃 12Vac 繞組
- **風險（repo 已記錄）**：
  - 賣家公告部分二手以全新欄位上架，**須確認本件狀況**
  - 「300W×2」是行銷文案，不是規格
  - 必須索取完整電路圖，確認 ±DC 偵測、掉電釋放
  - **板上繼電器的 DC 分斷能力通常沒有標示**，這是最大的未知

### 方案 B：自製保護板

- 以 UPC1237 IC 或分立電路自行設計，KiCad 畫板
- **優點**：電路全透明、繼電器可自選、可與本專案其他板統一風格
- **缺點**：多一輪 PCB 打樣與除錯，延後整機完工

### 建議決策路徑

1. 先買一片方案 A 模組（$258）**作為驗證與學習用**，不直接裝進成機
2. 到貨後反推電路圖、實測延遲時間與 DC 觸發門檻
3. 確認繼電器料號，查其 DC 分斷規格
4. **若繼電器不合格**（極可能）→ 換繼電器，或轉方案 B
5. 最終成機用哪一版，依實測結果決定

這條路徑的成本是 $258 和一點時間，換到的是「不把未知規格的板子裝進會燒喇叭的位置」。

## 5. 繼電器選型 —— 最容易踩的坑

**核心問題：交流額定不等於直流額定。**

一般繼電器標示如「10A 250VAC / 10A 30VDC」。喇叭保護的實際工況是：在故障時切斷一條**帶著 ±30V DC、流過低阻抗喇叭**的電路。直流沒有過零點，拉弧不會自行熄滅，觸點可能燒黏（welding）而失去保護作用。

**選型要求：**

| 項目 | 要求 |
|---|---|
| DC 分斷電壓 | ≥ 本機軌壓（±30V 等級 → 至少 30VDC，建議 48VDC 以上餘裕） |
| DC 分斷電流 | 故障電流 = 軌壓 ÷ 喇叭阻抗。±30V / 8Ω ≈ 3.75A；4Ω 喇叭 ≈ 7.5A |
| 觸點材質 | 建議 AgSnO₂ 或 AgNi，避免純銀（易硫化） |
| 接點形式 | 雙刀（DPDT / 2 Form C），左右聲道各一組，或雙繼電器 |
| 線圈電壓 | 配合 12Vac 整流後的約 15～16Vdc → 選 **DC12V 線圈**，但須確認 16V 下線圈耐受；或加穩壓 |

**待確認：** 繼電器線圈電流 × 數量 + 控制電路靜態電流 = 12Vac 繞組的最小需求。典型 DC12V 中功率繼電器線圈約 30～40mA，兩顆約 80mA，加控制電路估 150mA 以內。**此為估算，非量測。**

**參考做法**：部分設計把兩組觸點**串聯**用於同一聲道，以提升 DC 分斷能力（拉弧電壓分擔到兩個間隙）。這會用掉一顆雙刀繼電器只保護一個聲道，成本翻倍但安全性顯著提升。值得評估。

## 6. 一次側軟啟動（浪湧限制）

與保護電路同屬「尚未設計」清單，且兩者共用啟停邏輯，一併規劃。

**問題**：每軌 20,000µF，總計 40,000µF。上電瞬間電容等同短路，湧流僅受變壓器阻抗與線阻限制，可達數十安培。加上環形變壓器本身的磁飽和湧流，很容易打跳家中斷路器或熔斷保險絲。

**標準做法**：一次側串聯 NTC 熱敏電阻或功率電阻，延遲 0.5～2 秒後以繼電器短路旁通。

| 元件 | 待確認 |
|---|---|
| NTC 規格 | 常溫阻值（典型 5～10Ω）、額定電流、能量額定（焦耳） |
| 旁通繼電器 | AC250V 額定，觸點電流 ≥ 整機最大一次側電流 |
| 延遲時間 | 需長於電容充電時間，短於 NTC 過熱時間 |
| 一次側保險絲 | 慢熔型（Slow-blow / T 型），額定待整機功率確認後計算 |

⚠️ **一次側是市電電路。** 設計與施作涉及觸電與火災風險，必須有適當的絕緣距離、線徑與保護接地（PE）。`docs/01` 已註明「保護接地 PE 的機殼連接不可由訊號 GND 替代」。

## 7. 與現有電路的介面

**現有 pin 8 靜音支路的定位轉變：**

目前 JP1/JP2 是手動跳線。加入保護板後，靜音應改為**受控**，並與繼電器動作協調：

```
上電：軟啟動旁通 → 電源穩定 → 解除 MUTE → (延遲) → 繼電器接通喇叭
掉電：偵測 12Vac 消失 → 立即斷開繼電器 → (可同時) 拉回 MUTE
故障：偵測 DC → 立即斷開繼電器
```

`docs/01-設計規格.md` 已註明 JP1/JP2 「可於下一版改成額定足夠的雙極開關」，且「接點開路時可能承受接近 36V DC，建議選 ≥60V DC 額定」。若改為電子控制，該節點的耐壓要求同樣適用。

**注意**：兩個 MUTE 節點不直接相接（repo 既有規則），控制電路必須維持這個隔離。

## 9. 保護電路的驗收方法（未來實機用）

記錄於此，供 `docs/04-上電與驗收.md` 整合。**所有測試在假負載上進行，不接真實喇叭。**

| 測試 | 方法 | 通過條件 |
|---|---|---|
| 開機延遲 | 示波器同時看電源軌與繼電器觸點 | 觸點接通時 DC 偏移已在門檻內 |
| 正 DC 故障 | 以電阻從 VCC 注入到輸出節點模擬 | 繼電器斷開 |
| 負 DC 故障 | 同上，從 VEE 注入 | 繼電器斷開 |
| 掉電釋放 | 拔市電，示波器看觸點與輸出殘壓 | 觸點先斷、輸出後衰減 |
| 單軌掉電 | 拆一軌保險絲 | 繼電器斷開 |
| 誤動作 | 播放大動態低頻訊號至接近削波 | 繼電器不動作 |

⚠️ DC 故障注入測試會使 IC 承受異常工況，**在 IC 到貨且有備品之後再做**，或先以訊號產生器模擬偵測節點電壓，不直接破壞放大電路。
