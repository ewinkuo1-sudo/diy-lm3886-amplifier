# V0.2 設計規格

> 2026-09-16 採購更新：已下單雙 22Vac＋單 12Vac 變壓器及 LM3886T 拆機品，均待到貨。現行規劃以 [採購後修訂計畫](09-purchased-plan.md) 為準；本頁 V0.2 的 300VA／25Vac、40W／50W 及相關計算保留為舊版參考，不代表已購硬體的性能或驗收要求。

本版規劃內建線性電源的純後級，外接 Eversolo DAC-Z10 的 RCA 前級輸出，音量由 Z10 控制。數值分為原廠條件、專案選擇及計算估算；沒有實測性能宣稱。

## 範圍與訊號路徑

左右聲道各一顆 LM3886T，非反相接法。RCA 訊號依序經 2.2µF 薄膜隔直電容、1k 串聯電阻進入正相輸入，22k 提供輸入偏壓回路，插座側另有 1M 洩放。本機由 DAC-Z10 的可調 RCA 輸出驅動；原廠 2.5Vrms／0dBFS 全電平超過本設計滿功率需要，詳見[Z10 電平搭配](07-z10-interface.md)。

20k 回授及 1k 回授下臂設定約 21 倍中頻增益。47µF 無極性回授電容使 DC 增益趨近 1，減少 DC 偏移放大。加入輸入 1k／22k 分壓後，中頻整機增益約 20.09 倍；實際結果還包括訊源阻抗、元件誤差與 IC 頻率響應。

輸出腳先接 2.7Ω／2W 與 100nF 串聯的 Zobel 支路，再經 0.7µH 與 10Ω／2W 並聯的隔離網路送往假負載。回授取自電感之前。這些值是本專案的起始選擇，需以 PCB 原型確認高頻穩定度。

## IC 腳位與靜音

| 腳位 | 網路／用途 |
|---|---|
| 1、5 | VCC，兩腳都接正電源；符號中重疊顯示 |
| 2、6、11 | NC，不接線 |
| 3 | 功率輸出，接回授及輸出網路 |
| 4 | VEE，負電源 |
| 7 | GND，電源中點／訊號參考 |
| 8 | 各聲道 MUTE 節點 |
| 9、10 | 反相、正相輸入 |

來源：[TI SNAS091C，圖 1–2、Application Information](https://www.ti.com/lit/ds/symlink/lm3886.pdf)。原廠最低穩定閉迴路增益為 10；不能單純調低回授比來配合大輸出 DAC。

每聲道 pin 8 → 22k → RUN 跳線 → VEE。跳線開路時靜音，閉合後由負電源汲取電流解除靜音。100µF 靜音電容正端接 GND、負端接 MUTE。原廠要求解除靜音電流超過 0.5mA；±20V 至 ±41V 的本版計算約 0.79–1.75mA，詳見估算報告。

`22k × 100µF = 2.2s` 只是元件 RC 時間常數，**不等於固定的開機或關機靜音時間**。啟停行為受 pin 8 內部電路與電源變化影響，待量測。JP1／JP2 可於下一版改成額定足夠的雙極開關；兩個 MUTE 節點不直接相接。接點開路時可能承受接近 41V DC，建議選 ≥60V DC 額定。

## 電源與接地

J5 依序為 1=VCC、2=GND、3=VEE；這是正、零、負三線電源，不可把單顆 70V 電源的兩端直接當作本機雙電源。

成機電源在機殼內，候選為 300VA／兩組獨立 25Vac 次級、雙橋整流及每軌 20,000µF。J5 改為內部電源線束插座，對接電源圖 J203。標稱市電負載下約 ±33V，高市電空載可能接近 ±41V；實際值待料號與量測確認。詳見[內建電源規劃](05-internal-power.md)。±20V 限流實驗電源只用於放大板初步測試。

每聲道正負軌各有 100nF 及 470µF／63V 去耦；470µF 只負責本地儲能，不替代整機電源濾波。負電源的 470µF 正端接 GND、負端接 VEE。

原理圖上的 GND 為相同電氣網路，但 PCB 必須分開安排輸入、回授、Zobel、喇叭回流至合適匯流點，避免大電流流經輸入地線。100nF 去耦與 Zobel 靠近 IC；輸入接線遠離電源及喇叭線。以上佈線原則參照 [TI datasheet 的 Layout, Ground Loops and Stability](https://www.ti.com/lit/ds/symlink/lm3886.pdf)。

## 散熱與保護邊界

選 LM3886T 非絕緣封裝；金屬背板為 VEE，安裝到接地散熱器／機殼時需合適的絕緣介面與螺絲絕緣套。不可把 LM3886TF 的熱阻當成 T 封裝相同；若改料必須重算。[TI 封裝說明，圖 2 註 1](https://www.ti.com/lit/ds/symlink/lm3886.pdf)

散熱初選每聲道 ≤0.4°C/W、絕緣介面 ≤0.3°C/W，兩者都是選型條件。估算對象為 8Ω 電阻及機內 40°C 環境；真實喇叭阻抗與相角可能加重熱負擔。詳見[計算](02-calculations.md)。

放大板有 IC 內建保護與手動靜音；V0.2 電源次級圖加入整流、儲能、洩放及未定額定值的次級保險絲位置。一次側保險絲與浪湧控制、單軌掉電監測、喇叭 DC 偵測及輸出繼電器尚未完成。上電使用受限流保護的實驗電源與假負載。後續喇叭保護需驗證正負 DC 故障、繼電器 DC 斷開能力、延遲接通與快速斷開；不能以靜音功能替代。
