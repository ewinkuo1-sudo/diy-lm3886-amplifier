# V0.3 C 方案內建電源與整機規劃

兩顆 LM3886T 構成雙聲道純後級，由 Eversolo DAC-Z10 的可調 RCA 輸出控制音量。兩聲道共用正負主電源，非橋接、非並聯，也非左右獨立的雙單聲道電源。

## 主電源接法

已下單變壓器的賣場規格為 AC110V，兩組獨立 22Vac＋單 12Vac，標示 200W；VA、各繞組電流、頻率額定、調整率與熱保護待確認。兩組主次級保持彼此獨立：

1. 第一組 22Vac 接 J201，經 F201 接 BR1 AC 端。BR1 正端為 VCC，負端為 GND。
2. 第二組 22Vac 接 J202，經 F202 接 BR2 AC 端。BR2 正端為 GND，負端為 VEE。
3. BR1 負端與 BR2 正端於儲能電容匯流點形成 GND。AC 端不預先互連，不可混用單橋中心抽頭接法。
4. C201、C202 正端接 VCC、負端接 GND；C203、C204 正端接 GND、負端接 VEE。每顆 10,000µF／63V，每軌兩顆並聯成 20,000µF。
5. 每軌並聯 100nF／100V 薄膜旁路及 2.2kΩ／2W 洩放電阻。
6. J203 的 1／2／3 接放大板 J5 的 1／2／3，分別為 VCC／GND／VEE。兩份獨立原理圖需實際線束連接。

兩顆整流橋、四顆主電容全部未購。橋候選至少 15A／200V，KBPC2510 只是一個候選，不代表已選定料號；仍核對浪湧電流、冷卻與真實腳位。AC1／AC2／P／N 是原理圖功能端子，尚未指定 footprint。

## 12Vac 與控制

12Vac 優先留給雙聲道喇叭 DC 保護、繼電器及啟停控制，尚未畫成可施工的控制電路。先確認繞組電流，再依模組規格決定 AC12V 直入或整流、濾波、穩壓成 DC12V。整流後不等於 DC12V；空載電壓也需量測。

整機要求正負 DC 故障偵測、開機延遲接通、掉電快速斷開、雙軌監測與過溫控制。兩個 MUTE 節點不直接相接；測試跳線不取代整機自動控制。繼電器須核對實際 DC 斷開能力。

## 電壓與功率估算

依 22Vac 假設估算約 ±30V 等級。高市電 +10%、空載調整率 +8% 情境得到約 ±35.8V，36V 僅用作熱情境，不是保證上限。繞組額定電流未知，不能保證 2×40W。30～40W／8Ω 為探索範圍，最終以削波、雙聲道連續負載及溫升測試定額定。

以下數字由 `python3 tools/mains_budget.py` 計算，**沒有硬體量測**；改動假設後重跑該腳本並更新本節。試算前提：22Vac 視為額定負載電壓（若實際為空載值，下表會高估）；市電 110V／60Hz ±10%，空載調整率假設 +8%；兩組獨立次級各接全橋、DC 串接；四顆 10,000µF／63V，每軌兩顆並聯；導通二極體帶載每顆 1.1V、空載 0.6V，不含線阻、ESR、充電角與變壓器動態下陷。

`Vpeak=√2×Vac−2Vf`；`紋波=Irail/(2×60×0.020)`；`平均值=峰值−紋波/2`。30W、40W 是計算負載，不表示供電一定支持。

空載、放電與儲能：+10% 市電、+8% 空載調整率下 `22×1.10×1.08×√2−1.2 = 35.76V／軌`；36V 時每顆 2.2k 洩放電阻耗散 0.589W（候選 2W，仍須機內降額）；每軌 `RC=44.0s`，僅靠洩放電阻從 36V 降至 5V 約 86.9s，**實際斷電後仍要量殘壓**；兩軌 36V 總儲能約 25.92J，浪湧限制需按充電與快速關開情境設計。

還不能定案：變壓器持續供電能力與保險絲額定（等繞組電流、VA、熱與浪湧資料）；電容紋波額定與整流橋散熱（電容 −20% 容差會讓紋波增為 1.25 倍）；12Vac 全橋濾波約 15～16Vdc、空載可能更高，**AC12V 與 DC12V 保護板不得混接**。
